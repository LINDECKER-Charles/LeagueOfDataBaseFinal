## Ce qui change

LeagueOfDataBase s'installe comme une application sur Windows, sur macOS et sur Android. On
y retrouve tout le site, dans votre langue et avec votre compte : builds, favoris, profil.

Les applications se mettent à jour d'elles-mêmes : sur ordinateur au lancement, sur
Android sans repasser par le store pour la plupart des nouveautés.

## Pourquoi

L'application Android n'était jusqu'ici qu'une fenêtre sur le site en ligne, et il n'y avait
pas d'application pour ordinateur.

## Détails

- Windows et macOS : application signée ; elle vérifie ses mises à jour au lancement puis
  régulièrement.
- Android : disponible sur Google Play ; les liens vers le site s'ouvrent dans l'application
  quand elle est installée.
- Connexion par e-mail, pseudo ou Google, comme sur le site.
