## Ce qui change

Dès qu'un patch sort, le site en récupère les données et les images, dans toutes les
langues. Les pages du nouveau patch sont prêtes à votre première visite, sans écran de
chargement.

Les patchs plus anciens restent consultables. Le premier qui ouvre une version ancienne
peut encore voir quelques images se compléter pendant qu'elles arrivent.

## Pourquoi

Jusqu'ici, un patch n'était préparé qu'à la première visite. Le premier joueur de chaque
langue attendait donc devant un écran de chargement.
