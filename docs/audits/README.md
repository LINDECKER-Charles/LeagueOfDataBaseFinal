# Audits

Les audits datés du projet (performance, sécurité, observabilité) et leurs plans de
correction ne sont pas publiés : le dépôt est public, et un audit décrit des faiblesses avant
qu'elles soient toutes corrigées. Ils restent sur le poste du mainteneur, dans ce dossier,
ignorés par Git (`/docs/audits/*`).

Ce qu'un audit a changé se lit dans le code, dans les entrées du
[changelog](../changelog/README.md) et dans l'historique Git. Une vulnérabilité se signale en
privé : [`SECURITY.md`](../../SECURITY.md).
